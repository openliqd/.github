# OpenLiqd organization profile

This repository contains the public organization profile, brand assets and shared contribution guidance. Keep changes focused on those responsibilities.

- Follow CONTRIBUTING.md for commit and PR conventions.
- Write public content in English.
- Preserve the established OpenLiqd mark and visual identity.
- Keep product claims tied to verified evidence. Local tests and forks do not establish public deployment or independent audit status.
- Check Markdown links and SVG rendering after relevant edits. There is no application build or runtime test suite in this repository.
- Keep SVGs self-contained: no scripts, remote fonts or embedded external resources.
- Do not publish local paths, credentials, private operational notes or unpublished research results.
